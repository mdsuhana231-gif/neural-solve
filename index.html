📖 Method Reference

Formulas, convergence orders, and key properties for all numerical methods covered.

Root Finding

Bisection Method

c = (a + b) / 2

Halves the interval each iteration. Very slow but always converges if f(a)·f(b) < 0.

Order: Linear

Newton-Raphson

x₁ = x₀ - f(x₀)/f'(x₀)

Fastest for smooth functions. Quadratic convergence. Fails if f'(x)=0.

Order: Quadratic

Secant Method

x₂ = x₁ - f(x₁)(x₁-x₀)/(f(x₁)-f(x₀))

No derivative needed. Uses two previous points. Superlinear convergence (~1.618).

Order: ~1.618

Regula Falsi

c = a - f(a)(b-a)/(f(b)-f(a))

Combines bisection and secant. Guaranteed convergence, faster than bisection.

Order: Linear+

Linear Systems

Gauss Elimination

m = A[i][k]/A[k][k]; Rᵢ -= m·Rₖ

Direct method. Reduces to upper triangular form then back-substitutes. O(n³).

Direct

Gauss-Jordan

Reduce to identity matrix (RREF)

Eliminates both above and below pivot. No back-substitution needed.

Direct

LU Decomposition

A = L·U; Ly=b, Ux=y

Factors A into lower and upper triangular matrices. Efficient for multiple right-hand sides.

Direct

Jacobi / Gauss-Seidel

xᵢ = (bᵢ - Σaᵢⱼxⱼ) / aᵢᵢ

Iterative methods. Gauss-Seidel uses updated values immediately — ~2× faster.

Iterative

Numerical Integration

Trapezoidal Rule

∫ ≈ h/2 [f(x₀) + 2Σf(xᵢ) + f(xₙ)]

Approximates area with trapezoids. O(h²) error. Good for linear-ish functions.

Error: O(h²)

Simpson 1/3 Rule

∫ ≈ h/3 [f₀ + 4f₁ + 2f₂ + ... + fₙ]

Fits parabolas through triplets. Much more accurate than Trapezoidal. Needs even n.

Error: O(h⁴)

Simpson 3/8 Rule

∫ ≈ 3h/8 [f₀ + 3f₁ + 3f₂ + 2f₃ + ...]

Uses cubic polynomials. Requires n divisible by 3.

Error: O(h⁴)

Differential Equations (ODE)

Euler Method

yₙ₊₁ = yₙ + h·f(xₙ, yₙ)

Simplest ODE solver. O(h) error — inaccurate for large h.

Error: O(h)

Modified Euler (Heun)

Predictor + Corrector step

Predict-correct approach. O(h²) error — more accurate with small extra cost.

Error: O(h²)

Runge-Kutta 4 (RK4)

y₁ = y₀ + h(k₁+2k₂+2k₃+k₄)/6

Gold standard for ODEs. O(h⁴) accuracy with only 4 evaluations per step.

Error: O(h⁴)

Numerical Differentiation

Forward Difference

f'(x) ≈ [f(x+h) - f(x)] / h

One-sided approximation. O(h) error. Use when backward values unavailable.

Error: O(h)

Central Difference

f'(x) ≈ [f(x+h) - f(x-h)] / 2h

Best accuracy for same h. O(h²) error — twice as accurate as one-sided methods.

Error: O(h²)

Backward Difference

f'(x) ≈ [f(x) - f(x-h)] / h

Uses previous point. O(h) error. Useful when forward data is unavailable.

Error: O(h)
